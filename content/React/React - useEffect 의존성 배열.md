# React - useEffect 의존성 배열

## 질문

`useEffect`의 의존성 배열이 빈 배열일 때, 아예 없을 때, 값이 들어 있을 때는 각각 어떻게 동작하나요?

## 최적 답변

빈 배열을 넘기면 마운트 직후 한 번만 실행됩니다. 의존하는 값이 없으니 다시 실행될 이유도 없습니다.

배열을 아예 넘기지 않으면 렌더링될 때마다 매번 실행됩니다. 이 경우 이펙트 안에서 상태를 바꾸면 다시 렌더링되고 이펙트가 또 실행되는 무한 루프가 생기기 쉽습니다.

배열에 값을 넣으면 그 값이 바뀔 때마다 실행됩니다. 이때 이전 props와 state로 클린업 함수가 먼저 돌고, 그다음 새 값으로 본문이 실행됩니다.

## 예시 코드

```tsx
useEffect(() => { /* ... */ }, []);        // 마운트 시 1회
useEffect(() => { /* ... */ });            // 매 렌더마다
useEffect(() => { /* ... */ }, [userId]);  // userId 바뀔 때마다
```

## 반드시 포함할 키워드

- 빈 배열은 마운트 1회
- 배열 없음은 매 렌더
- 매 렌더는 무한 루프 위험
- 값 변경 시 실행
- 클린업 먼저 후 본문

## 자주 틀리는 표현

- 의존성 배열을 생략하면 빈 배열과 같이 한 번만 실행된다.
- 의존성이 바뀌면 클린업 없이 본문만 다시 실행된다.

## 한 줄 요약

빈 배열은 마운트 시 1회, 배열 생략은 매 렌더마다(무한 루프 위험), 값이 있으면 그 값이 바뀔 때 이전 클린업 후 본문이 실행된다.
