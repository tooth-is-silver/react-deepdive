# Network - HTTP status code

## 질문

HTTP 상태 코드는 크게 어떻게 분류되고, `301`과 `302`, `401`과 `403`은 각각 어떻게 다른가요?

## 최적 답변

HTTP 상태 코드는 첫 자리로 의미를 분류합니다. `2xx`는 성공(`200 OK`, `201 Created`, `204 No Content`), `3xx`는 리다이렉트(`301`, `302`, `304`), `4xx`는 클라이언트 잘못(`400`, `401`, `403`, `404`, `429`), `5xx`는 서버 잘못(`500`, `502`, `503`, `504`)입니다. 앞자리만 봐도 실패의 책임이 클라이언트에 있는지 서버에 있는지 구분할 수 있습니다.

`301 Moved Permanently`는 리소스가 영구 이동했다는 뜻이라 브라우저·검색엔진이 새 URL을 캐시하고 이후 바로 새 주소로 갑니다. `302 Found`는 임시 이동이라 원래 URL을 계속 사용합니다. `401 Unauthorized`는 이름과 달리 "인증되지 않음"에 가까워서, 누구인지 확인이 안 됐거나 자격 증명이 없거나 유효하지 않은 경우입니다. 반면 `403 Forbidden`은 인증은 됐지만 그 리소스에 접근할 권한이 없는 경우입니다. 즉 401은 "너가 누군지 모르겠다", 403은 "누군지는 알지만 안 된다"로 구분합니다.

## 반드시 포함할 키워드

- 2xx 성공
- 3xx 리다이렉트
- 4xx 클라이언트 오류
- 5xx 서버 오류
- 301 영구 이동
- 302 임시 이동
- 401 미인증
- 403 권한 없음

## 자주 틀리는 표현

- 401은 권한이 없는 것이고 403은 로그인이 안 된 것이다.
- 301과 302는 똑같이 새 URL로 보낸다.

## 한 줄 요약

앞자리로 2xx 성공·3xx 리다이렉트·4xx 클라이언트·5xx 서버 오류를 나누고, 301은 영구·302는 임시, 401은 미인증·403은 권한 없음이다.
